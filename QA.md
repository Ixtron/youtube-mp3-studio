# Проверка версии 4.0 preview

Дата: 31 октября 2026.

## Пройдено

- Пользователь сообщил об успешной авторизации и запуске Zapret на основном ПК.
- Все автоматические проверки GitHub Actions прошли на Windows runner.

- 15 автоматических тестов движка, интерфейса и защиты публикации.
- Установщик в Windows PowerShell 5.1: установка, кэш, отказ при неправильной
  SHA-256, сохранность отдельной папки пользовательских данных.
- Из исходников: загрузка короткого публичного ролика в MP3 и M4A с обложками;
  длительность и наличие обложек подтверждены чтением готовых файлов.
- Из готового EXE: ввод ссылки, добавление в очередь, скачивание и обработка MP3;
  сохранён 19-секундный MP3 с обложкой, итог — один трек, ноль ошибок.
- Повтор той же ссылки из EXE: пропуск существующего файла, ноль новых треков,
  ноль ошибок. Дубликат не создаётся.
- Все 59 файлов встроенного Zapret совпадают с официальным ZIP 1.10.4.
- Git index проверен по списку разрешённых исходников и признакам секретов.
  Cookies, браузерные данные, логи, музыка и бинарники в Git не включены.
- Проверены повреждённые ID3-теги, старые имена MP3, отмена во время паузы,
  сохранение ошибок для повтора и блокировка второго рабочего потока.

## Ещё не подтверждено

- Запуск на чистой Windows без установленного Python и инструментов разработчика.
- Чтение cookies из разных браузеров и работа стратегий у разных провайдеров.
- Большие плейлисты, длительная работа и отмена непосредственно во время FFmpeg.
- Полный набор лицензий и соответствующих исходников сторонних бинарников для
  публичного распространения. В частности, локальная сборка FFmpeg использует GPLv3.
- Установка через публичную команду irm: требует опубликованного GitHub Release.

Текущий статус: предварительный выпуск для проверки на других ПК.
