# YouTube MP3 Studio — 4.0 preview

Windows-приложение для загрузки аудио с YouTube. Тёмный интерфейс, очередь ссылок,
MP3/M4A/исходный аудиоформат, обложки, метаданные, пауза и повтор ошибочных ссылок.

## Статус

Исходники предварительной версии опубликованы в этом репозитории. Готовый
публичный бинарный релиз ещё не выпущен. Команда ниже заработает только после
публикации проверенного Release с нужными файлами:

```powershell
irm https://raw.githubusercontent.com/Ixtron/youtube-mp3-studio/main/install.ps1 | iex
```

`irm` получает скрипт, `iex` выполняет его. Проверяйте адрес и исходник перед запуском.
Установщик использует `%LOCALAPPDATA%\YouTubeMP3\versions`, проверяет SHA-256 архива,
повторно использует установленную версию и не требует прав администратора.
Контрольная сумма проверяет целостность, но не заменяет доверие к владельцу репозитория.
Поддержка первого релиза: Windows 10/11 x64. Нужен доступ к GitHub и YouTube.

## Локальный запуск

Python 3.14 x64:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe app.py
```

Для загрузки поместите `ffmpeg.exe`, `ffprobe.exe`, `node.exe` в `vendor/`
или добавьте эти инструменты в PATH. `yt-dlp-ejs` устанавливается вместе с зависимостями.
Встроенный вход использует pywebview/WebView2. Google может ограничить вход
во встроенном браузере; доступны также cookies из выбранного пользователем браузера.
При ошибке чтения cookies приложение показывает ошибку и не переключается на другой
аккаунт автоматически.

## Как пользоваться

1. Вставьте одну или несколько ссылок и добавьте их в очередь.
2. Выберите формат, папку и при необходимости режим плейлиста.
3. Нажмите «Начать загрузку».

Ссылки `watch?v=...&list=...` в режиме «Авто» скачиваются как одно видео;
для всего списка выберите «Плейлист». Качество MP3 задаётся в кбит/с и не улучшает
исходное аудио. Обложки добавляются к MP3/M4A, метаданные — независимо от обложек.
Имена файлов включают ID ролика: это предотвращает совпадения названий.
Существующие файлы распознаются по ID в имени, старые MP3 — также по URL в ID3.
Если у старого MP3 нет ID ни в имени, ни в тегах, точно определить его источник нельзя.
Учёт раздельный для MP3/M4A. Удалённые файлы можно скачать снова.

Пауза и отмена применяются при следующем вызове обработчика загрузки. Во время
сетевого ожидания или работы FFmpeg это может занять время; новая загрузка не
запустится до завершения предыдущей. Повтор ошибок повторяет ссылку целиком,
пропуская уже сохранённые треки. Для плейлиста возможен частичный успех.

Zapret 1.10.4 включается кнопкой «Включить Zapret». Можно выбрать встроенную
стратегию; по умолчанию используется `general (ALT).bat`. Windows запрашивает UAC.
Для остановки закройте окно `zapret`. Программа не завершает чужие процессы
`winws.exe`. Автозапуска и установки системной службы нет.
В комплект берётся чистый [официальный архив](https://github.com/Flowseal/zapret-discord-youtube/releases/tag/1.10.4)
с проверкой опубликованной SHA-256, а не пользовательская папка.

## Личные данные

- Cookies и настройки хранятся в `%LOCALAPPDATA%\YouTubeMP3\data`.
- Старые cookies автоматически не копируются. По умолчанию загрузка идёт без входа.
- Логи интерфейса не отправляются на сервер и не сохраняются в репозитории.
- Пользовательская музыка по умолчанию хранится в `Music\YouTubeMP3`.
- `.gitignore` исключает cookies, браузерные профили, медиа, логи, сборки и бинарники.
- Перед коммитом запустите `python scripts/audit_publish.py`: проверяется точное
  содержимое Git index, список разрешённых файлов и признаки секретов.

Не загружайте исходную рабочую папку целиком. Не добавляйте токены в исходники.
Сканер — дополнительная проверка, а не математическая гарантия отсутствия секретов.

## Проверки и сборка

```powershell
python -m unittest discover -s tests -v
powershell -NoProfile -ExecutionPolicy Bypass -File tests/test_installer.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/fetch_zapret.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build.ps1
```

`ExecutionPolicy Bypass` здесь действует только для отдельного процесса PowerShell
и позволяет выполнить локальные проверенные скрипты; системная политика не меняется.
Сборка: `dist/YouTubeMP3/YouTubeMP3.exe`. Python на компьютере пользователя не нужен.
Вход собран отдельным `LoginHelper.exe`, запускаемым без консольного окна.

GitHub Actions проверяет исходники и тесты. Публикация релиза автоматически не включена.
Результаты выполненной проверки и оставшиеся ограничения: [QA.md](QA.md).
Локальный переносимый архив создаётся командой `python scripts/package_preview.py`.
Упаковщик проверяет состав сборки, соответствие Zapret официальному архиву,
создаёт список файлов с SHA-256 и проверяет целостность готового ZIP.
Перед публичным выпуском требуется:

- проверить EXE на чистой Windows без Python;
- вручную проверить вход, закрытие окна входа и выход из аккаунта;
- проверить большую очередь, недоступные элементы плейлиста, отмену во время FFmpeg;
- выбрать лицензию исходного проекта и приложить лицензии всех распространяемых
  компонентов, включая условия конкретной сборки FFmpeg и соответствующие исходники;
- упаковать содержимое `dist/YouTubeMP3` в `YouTubeMP3-windows-x64.zip`;
- выпустить стабильный тег вида `v4.0.0`, приложить ZIP и `SHA256SUMS.txt` с записью
  `<64 hex characters>  YouTubeMP3-windows-x64.zip`;
- проверить `irm` на другой Windows после публикации.

До этого локальный EXE считается предварительной сборкой.
