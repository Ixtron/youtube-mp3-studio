# YouTube MP3 Studio 4.0 preview 2

Предварительный выпуск для проверки на других Windows 10/11 x64.

Исправления по результатам проверки:

- Ctrl+V работает на русской и английской раскладках, включая замену выделения.
  Ctrl+A/C/X также не зависят от раскладки.
- Общий прогресс плейлиста: «7 из 100». Скачанные, существующие и ошибочные
  записи считаются отдельно; текущая песня засчитывается после обработки аудио.
- Отдельная полоса текущего файла: процент, размер, скорость и время до конца файла.
  Чтение списка, преобразование аудио и добавление обложки показываются явно.
- Журнал открывается отдельной кнопкой, чтобы очередь и прогресс помещались
  в небольшом окне.

Для обновления закройте старое окно приложения и выполните ту же команду:

Запуск из PowerShell:

```powershell
irm https://raw.githubusercontent.com/Ixtron/youtube-mp3-studio/main/install.ps1 | iex
```

При первом запуске установщик скачивает приложение, FFmpeg, Node.js и Zapret
из официальных источников и проверяет SHA-256. Это может занять несколько минут.
ZIP приложения в этом релизе содержит EXE и Python-зависимости; для автоматической
подготовки остальных компонентов используйте команду выше.

Вход в YouTube и запуск Zapret подтверждены пользователем на основном ПК.
Проверены 22 автоматических теста и установщик. Реальный плейлист из четырёх
песен скачан в MP3 с обложками; повторный запуск корректно пропустил все четыре.
Совместимость на другом ПК и большие плейлисты продолжают проверяться.

Cookies и настройки сохраняются только в профиле текущего пользователя Windows.
Автоматической отправки cookies разработчику нет. Zapret включается вручную
кнопкой с запросом UAC. Поведение зависит от провайдера и выбранной стратегии.

Исходный код приложения доступен в репозитории. Лицензии Python-компонентов
включены в каталог `licenses`; исходник mutagen приложен отдельно.
